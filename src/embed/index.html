Embedding the playground

Six shapes a documentation page can take, from the whole playground down to a single rendered app. Every demo below is real — the same playground, in an iframe, running the ABAP it shows.

1 Editor and app

The default. The reader can change the ABAP and press Run. data-src points at the same file your page prints, so the printed code and the running code cannot drift apart. Give it height: an editor in 300 pixels is a keyhole. 

<div class="abap2ui5-demo"
     data-src="https://raw.githubusercontent.com/abap2UI5/samples/main/src/01/z2ui5_cl_smp_app_493.clas.abap"
     data-height="520"></div>
<script src="https://abap2ui5.github.io/playground/embed/abap2ui5-embed.js"></script>

2 The app on its own

For a paragraph about what an app does, not about how it is written. The ABAP still compiles and still runs — it is simply not on screen. This one reports its own height, so the frame fits what was rendered instead of guessing. 

<div class="abap2ui5-demo" data-view="app" data-src="…"></div>

3 Code that lives only in your page

When there is no file to point at. data-code carries the ABAP itself, deflated into the playground's URL fragment. Nothing has to be hosted, and the demo travels with the page. The class keeps the name your page gave it — the file it is put into is named after it, the way abapGit names one. 

<div class="abap2ui5-demo" data-code="CLASS z2ui5_cl_demo_inline DEFINITION PUBLIC…"></div>

4 Printed code beside the running app

The classic documentation shape: your own code block, styled and highlighted the way the rest of your manual is, with the result running next to it. The app half is a data-view="app" demo — the reader reads on the left and sees on the right. 

METHOD z2ui5_if_app~main.
  DATA(view) = z2ui5_cl_ui5_view_builder=>factory( ).
  view->ele( `Page`
      )->a( n = `title` v = `Side by side`
      )->tag( `Button`
          )->a( n = `text` v = `Press me` ).
  client->view_display( view->stringify( ) ).
ENDMETHOD.

5 Loading straight away

Only where the page is about its one demo — a tutorial step, a landing page. data-auto="1" skips the button. Put more than one of these on a page and you will feel it; see the last section. 

<div class="abap2ui5-demo" data-auto="1" data-src="…"></div>

6 A plain iframe, no script at all

When your documentation framework will not run custom JavaScript, or you want no dependency. Everything the loader does is in the URL anyway; what you give up is click-to-load and the automatic height. 

<iframe
  src="https://abap2ui5.github.io/playground/?embed=1&src=https://raw.githubusercontent.com/abap2UI5/samples/main/src/01/z2ui5_cl_smp_app_493.clas.abap"
  style="width:100%;height:520px;border:1px solid #ddd;border-radius:8px"
  loading="lazy" title="abap2UI5 example"></iframe>

loading="lazy" is not a substitute for the button: it only waits until the frame is scrolled near, and then several start at once.

Every attribute

AttributeWhat it does
data-srcURL of an ABAP file, or several separated by whitespace; the first is the app. This site and GitHub's raw hosts only.
data-codeABAP inline, for a demo that lives only in this page.
data-viewapp for the running app without the editor.
data-heightStarting height in pixels. Default 520, and a view=app demo grows past it when the app overflows it — an app laid out at 100% of its box never does, so for those this is the height it is read at.
data-labelThe text on the button.
data-auto1 to load without a click.
data-originWhere the playground is served from, if not this script's own.

For a documentation framework that swaps pages without reloading — Docusaurus, VitePress and friends — call window.abap2ui5Embed.setUp() after each navigation to pick up the new page's demos.

Why nothing loads until it is clicked

Each demo is a complete ABAP runtime plus an abaplint parse of nine hundred sources — a second or two of processor and a few hundred megabytes, per frame. Demos on the same page share the browser's cache, so the roughly 3 MB is paid once; the parsing is not. A page with ten examples that all booted on scroll would be the slowest thing in the manual.

That is the whole reason the loader renders a button. Reach for data-auto when the page has one demo and that demo is the point.
